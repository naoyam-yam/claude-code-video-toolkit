# 非MVPスコープ

明示的に**入れない**もの。理由も併記する。

| 項目 | 理由 |
|------|------|
| コミュニティ機能 | 事前決定メモで明示的に除外。差別化価値は「忘却の可視化」に集中する。 |
| 複数資格同時対応 | 単一資格で運用が安定してから横展開する（シナリオA）。 |
| 合格後の学習用途 | 最初は保留してよいと事前決定メモに明記。 |
| 詳細な課金設計・Stripe統合 | DoD完了・Phase 2（公開）まで先送り。 |
| 高精度なAI診断を前提にした機能 | 精密さより継続と復習効果を優先する方針と矛盾する。 |
| ログイン・アカウント/複数端末同期 | 匿名ローカル保存で開始。将来Supabase匿名認証で拡張。 |
| 通知機能 | MVPでは保留してよい（事前決定メモ§5. 設定）。 |
| 装飾的なAIコメント・診断的な煽り文言 | 分析画面で明示的に禁止。 |
| iOSネイティブアプリの継続開発 | HOKIRUはiOS版をそのまま延命しない（最重要前提）。品質到達後の二次展開として保留。 |
| R07法規120問（既存過去問）の公開UIでの利用 | 権利問題により`third_party_restricted`/`internal_reference_only`として隔離。 |

## MVP後、条件トリガーで着手するもの

- Phase 2（公開）到達後: Stripe課金、独自ドメイン、LP
- 複数端末同期の具体的ニーズが出た後: Supabase匿名認証への移行
- Phase 4（横展開）: 宅建・診断士・マン管など第2号機の資格選定
