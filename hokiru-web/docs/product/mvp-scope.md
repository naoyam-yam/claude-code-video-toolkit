# MVPスコープ

出典: Notion「HOKIRU 事前決定メモ」§MVP範囲 + v1.0 §4.3 DoD + `docs/strategy/v1.1-proposal.md` §4。

## 入れるもの

- ホーム・演習・復習・分析・設定の5画面
- 問題演習（4択・自信度・回答時間記録）
- 間違い履歴の記録（学習ログ）
- 再出題タイミングの調整（復習スケジューラー）
- 苦手論点の表示
- 今日やるべき復習の提示
- 法令根拠の表示
- 監修ステータスの表示（未監修ドラフト/監修中/監修済み）
- rightsStatus による公開可否ゲート
- 匿名ローカル保存（localStorage）
- 利用規約・プライバシーポリシー（匿名ローカル保存の説明を含む最小構成）

## 判定基準

- 学習ログが取れること。
- 個人別の復習間隔を変えられること。
- 毎日迷わず開ける導線があること（ホーム→復習の1タップ）。
- 精密さより継続と復習効果を優先すること。
