# トークン予算（Claude Pro前提）

v1.0 §5.3 をそのまま実装方針として採用する。

- 夜間ラン: 平日のみ・1夜1タスク・最大ターン数を制限して定額的に消費する
- 定時タスク: 毎朝1回＋週次1回のみ
- 週次上限に近づいた週は夜間ランを間引き、人間の対話利用を優先する
- 対話利用の規律: 1セッション1用件／資料は貼らずMCPで読ませる／定型作業は軽量モデルに任せる

## 縮退運用トリガー

| 状況 | 対応 |
|------|------|
| 週次利用量が上限の70%を超えた | 夜間ランを平日→隔日に間引く |
| 週次利用量が上限の90%を超えた | 夜間ランを停止し、DoD状況のIssueコメントのみ継続 |
| DoD残数が10未満 | 夜間ランの頻度を落とし、対話セッションでの仕上げに切り替えてよい |
